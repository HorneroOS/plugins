# Real-shell QA VM captures (2026-11-17)

Hornero shell main plus PluginKit 3 in the disposable QA VM (1280x800). Each file is one official extension enabled alone and its native bar popover captured on a given bar edge; the pointer position is found by sweeping the bar and accepting only the shell's own `debug dump` popout state naming that extension (deterministic, not image-diff based). Edges: `classic-top`, `classic-bottom`, `hornero-left`, `hornero-right`. Filename: `<id>.<edge or preset>.popover.png`.

These are real-shell captures of a representative set (bar indicators and popovers: pomodoro on all four edges; dual-clock, weather and sun-card on a vertical rail). Offscreen fixture renders of all 36 are in `../offscreen/`.
