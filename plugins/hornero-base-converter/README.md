# Hornero Base Converter

Dashboard card (`"placement": "dashboard"`) converting a validated decimal integer (absolute value at most `Number.MAX_SAFE_INTEGER`) to binary, octal and hex, and hex input back to decimal. Invalid digits for the base or out-of-range values show an error. Pure QML, no settings. Original HorneroOS code, MIT licensed. Plugin QML runs with your user privileges inside Quickshell; it is not sandboxed.
