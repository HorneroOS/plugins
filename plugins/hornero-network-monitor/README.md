# Hornero Network Monitor

Dashboard card (`"placement": "dashboard"`) showing download and
upload speeds plus session totals from the read-only PluginKit
`Network` service, formatted in human units (B/KiB/MiB/GiB/TiB).

No processes, no network access of its own, no settings.
Original HorneroOS code, MIT licensed. Plugin QML runs with your
user privileges inside Quickshell; it is not sandboxed.
