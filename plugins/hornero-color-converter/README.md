# Hornero Color Converter

Dashboard card (`"placement": "dashboard"`) converting validated `#RGB`/`#RRGGBB` hex to RGB and HSL, and RGB spin inputs (0-255) back to hex. Invalid hex shows an error and no color. Pure QML, no settings. Original HorneroOS code, MIT licensed. Plugin QML runs with your user privileges inside Quickshell; it is not sandboxed.
