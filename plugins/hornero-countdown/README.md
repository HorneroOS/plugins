# Hornero Countdown

Bar widget (`"placement": "bar"`) countdown timer with 5, 10
and 25 minute presets plus Start/Pause and Reset. Progress is
shown as a ring around the remaining time. At zero the ring and
text flash `DONE` visually; there is no sound.

Pure QML: no processes, no network, no settings. Original
HorneroOS code, MIT licensed. Plugin QML runs with your user
privileges inside Quickshell; it is not sandboxed.
