# Hornero Emoji

Emoji search for the launcher and a small picker card for the dashboard.

- **Launcher:** type `>emoji` and a few words (`>emoji grin`, `>emoji heart eyes`).
  Rows list matching emoji with their Unicode name; Enter copies the one you
  pick and closes the launcher. Needs a Hornero Shell with multi-row launcher
  results (shell docs/LAUNCHER.md, "Several rows"); on an older shell the
  launcher surface is skipped with a `launcher-contract-missing` diagnostic and
  the dashboard card keeps working.
- **Dashboard card:** a search field and a grid of buttons; clicking an emoji
  copies it with `wl-copy`.

## Settings (Control Center, Extensions)

| Setting | Default | Meaning |
| --- | --- | --- |
| `skinTone` | `default` | Tone applied to emoji that ship tone variants (308 of them). |
| `maxResults` | `12` | Rows in the launcher, emoji in the card (6 to 24). |
| `showGroup` | `true` | Show the emoji group beside the name. |

## Privacy

Everything is local. Nothing is recorded: there is no recent list, no history
and no network access (`networkHosts` is empty). The only process is `wl-copy`,
run when you click an emoji in the card.

## Data

`EmojiData.qml` is generated by `scripts/gen_emoji_data.py` from Unicode's
`emoji-test.txt` 16.0 (fully-qualified emoji; entries that differ only by skin
tone are folded into one entry with five variants).

Emoji data (c) 2024 Unicode, Inc., distributed under the Unicode License v3
(https://www.unicode.org/license.txt). The extension code is MIT.

The idea of a clipboard and emoji picker living in the launcher is studied from
Caelestia's Stowaway; no code or data of Stowaway is used (its kaomoji set is
GPL-3 and is not included).

The companion extension for the clipboard is `hornero-clipboard`.
